## Background

I'm a C# / .NET developer going deep on the Power Platform developer layer — plugins, PCF controls, custom connectors, Azure integrations. The goal is to understand the platform at the engineering level, not just the configuration level.

Each folder here maps to a specific thing I built and can defend in a technical conversation.
